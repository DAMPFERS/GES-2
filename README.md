# GES-2

На вашем текущем компьютере данные arduino-cli хранятся в двух местах:

1. Папка данных Arduino15 (главное хранилище)
Это основной каталог. Именно в нём лежат установленные платформы (ядра), служебные инструменты и индексные файлы, которые не смогли скачаться из-за ошибки 403.

Путь по умолчанию на Windows: C:\Users\vladr\AppData\Local\Arduino15

Что внутри важно: скопируйте всю папку целиком. В ней находятся подпапки packages (ядра, например arduino:avr) и tools (те самые serial-discovery и др.), а также конфигурация arduino-cli.yaml, если она там есть.

2. Папка скетчбука (Sketchbook) с библиотеками
Библиотеки, установленные через arduino-cli lib install (в вашем случае FastLED), хранятся не в Arduino15, а в отдельной папке «скетчбука», в подкаталоге libraries.

Путь по умолчанию: C:\Users\vladr\Documents\Arduino (иногда это может быть C:\Users\vladr\Arduino).

Что копировать: достаточно скопировать папку libraries (или весь скетчбук, если там нет ничего лишнего).

💻 Как перенести на новый компьютер
Установите arduino-cli на новом компьютере любым доступным способом (например, скопируйте исполняемый файл arduino-cli.exe и добавьте его в PATH). Без самого CLI скрипт не запустится.

Скопируйте папку Arduino15 с оригинального компьютера и поместите её в аналогичное место на новом:
C:\Users\<Имя_пользователя_на_новом_ПК>\AppData\Local\Arduino15

Скопируйте папку libraries (из скетчбука) в C:\Users\<Имя_пользователя_на_новом_ПК>\Documents\Arduino\libraries
